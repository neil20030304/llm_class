Notes on result shape
======================================================================
  - Every tool returns the structured payload at
    result['structuredContent']['result']; mcp_client.tool_result()
    grabs it directly. result['content'][i]['text'] is the same data
    serialized one JSON object per item — usable but redundant.
  - get_citations wraps each entry as {'citingPaper': {...}}; the other
    two tools return flat paper dicts directly.
  - get_paper exposes references as a *field* on the paper, not a
    separate endpoint — request via fields=references.title,...
  - When a paper's Semantic Scholar record is malformed (e.g. ReAct
    ARXIV:2210.03629), asking for `references.title` makes the server
    return isError=True. Always check tool_error() before parsing.
